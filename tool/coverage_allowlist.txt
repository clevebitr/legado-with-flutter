# 覆盖率门禁豁免名单（见 docs/dev/adr/0019-coverage-gate-must-detect-unmeasured-files.md）
#
# 每行一个仓库相对路径，允许行尾用 `#` 注释说明原因。
# 只允许三类文件进入本表（判据规格出处：ADR-0019 §2；本文档不复述完整判据）：
#   1. 仅特定平台或条件编译下可达，单元测试环境无法加载的实现文件；
#   2. 依赖真实设备或原生库、只能在 integration_test 或 tool/spike 中执行的入口文件；
#   3. 代码生成器的输入文件（如 drift 表定义）：其中声明只在生成期被分析、运行时不可达。
#      此类文件必须同时加 `// coverage:ignore-file`，否则仍会因阈值失败；
#      其正确性必须由别的测试（如 migration_test.dart 逐列比对）保证。
#
# 禁止把「暂时没写测试」的文件写进来：
# 新增条目必须在 PR 描述中给出理由。
# 条目若已经出现在覆盖率报告中，或文件已被删除，门禁会以退出码 3 判失败。
#
# 注意：手写文件若加了 `// coverage:ignore-file`，lcov 会把它整行从报告里移除，
# 因此它会被当成「未测量源文件」而失败；确需 ignore 时必须在本表登记并说明原因。
# 生成物（*.g.dart / *.freezed.dart / *.gr.dart / **/generated/**）无需登记，已自动排除。
#
# 示例（当前 3 条已登记豁免见文末「已登记的豁免项」）：
# lib/core/platform/system_ui_controller_android.dart  # 仅 Android 可达，由平台验收清单覆盖
