# ADR-0051 阅读体验（M14）：沉浸式菜单、目录增强、换源、排版轴与亮度

- **状态：** Accepted（2026-10-22，M14 规格前置；范围由 `DECISIONS.md` #11 的用户裁决给定，四项全做）
- **日期：** 2026-10-22
- **关联：** C-UI-1、C-UI-7、C-NET-9、ADR-0041、ADR-0042、ADR-0044、ADR-0050、
  `docs/dev/roadmap.md` §3.9（R1–R4）、`docs/dev/book-source.md` §6

## 背景

`roadmap.md` §3.9 把 M14 定为四项：底部阅读菜单（含进度/亮度）、目录面板增强、换源、排版扩展。
今天的阅读器只有常驻 AppBar 的两个图标、一张最简单的目录 `ListView`、四个设置轴（字号/行距/背景/翻页），
没有换源，也没有亮度。

换源是四项里唯一**动领域**的：要让用户从 A 源读到一半换到 B 源，必须按书名找到候选源、重取详情与目录、
把位置对齐到“同一章”，而书架的身份是 `(sourceUrl, bookUrl)`（ADR-0041 §决策 4）——换源等于换身份。
所以先把语义定死，再动代码。

## 决策

### 决策 1 三区点击 + 可隐藏的底部工具条（R1）

- 正文按宽度分成 **左 / 中 / 右** 三块：中间 ⅓ 唤出菜单，左右 ⅓ 翻页（分页模式）或上下滚一屏（滚动模式）。
  这是上游 `PageKeyConfig` 的默认语义，也让“点一下就出现菜单”不必依赖 AppBar。
- 唤出后：顶部 AppBar 与底部工具条同时出现（**沉浸式**：默认都没有），**4 秒无操作自动隐藏**，
  任何操作重置计时；返回/退出走 AppBar 的返回键（工具条不重复放）。
- 工具条内容（从左到右）：上一章 · **进度滑块** · 下一章 · 目录 · 设置 · 换源 · 亮度。
  进度滑块按**章节**定位（书的维度），旁边显示「第 N/M 章 · 本章 x%」；拖动只在松手时换章，
  拖动过程中只更新标签（否则每帧一次抓取）。
- **亮度是应用级遮罩**，不是系统亮度：`Container(color: black.withValues(alpha: level))`
  叠在最上层并 `IgnorePointer`，范围 0.2–1.0，默认 1.0。理由：Windows 没有统一可用的系统亮度 API，
  iOS/Android 要平台通道；遮罩在三个目标上行为一致、可测试，而且**不会**改用户的系统设置。
  系统亮度登记为未实现（触发 = 用户要求“调亮度时状态栏也要跟着变”）。

### 决策 2 目录：当前章居中 + 正倒序 + 搜索（R2）

- 打开目录时若当前章已加载，把列表滚到**当前章居中**（`ScrollController` 的初始偏移按行高估算），
  当前章高亮并带 `selected: true`。
- 正序 / 倒序是**视图**：只反转展示顺序，不改章节数据与进度索引（换序后点选仍回到正确的章）。
- 章节名搜索按大小写不敏感的子串匹配，空串显示全部；搜索不影响倒序。

### 决策 3 换源：跨源找候选 → 重取目录 → 按章节名对齐 → 迁移身份（R3）

- **候选**：用**当前书名**（`ReaderBook.name`）在聚合搜索的选源范围内搜一遍（复用
  `AggregateSearchBooks` 的合并/超时/隔离语义），排除当前源，按「书名完全相等 → 包含 → 其它」排序，
  最多 20 条。它是一份**候选列表**，不是结果页：没搜到就是空态，不报错。
- **切换**：选中候选后 `FetchBookInfo` + `FetchToc` 取新目录，然后按顺序对齐章节：
  同名 → 名称互相包含 → 同索引（clamp 到合法范围）。对齐只影响“打开哪一章”，不复制正文。
- **身份迁移**：书架行按 `(sourceUrl, bookUrl)` 存（ADR-0041 §决策 4），换源就是换身份。规则：
  1. 若新身份**已经有**一行（用户之前加过），不迁移，只切过去（进度按新身份写）；
  2. 否则若旧身份有行，把那一行的身份**改写**成新身份（`books` 的 `sourceUrl` / `bookUrl` / `tocUrl`
     与快照字段一起更新，`customOrder` / `status` / `isPinned` 保留）；
  3. 都没有（从搜索/详情直接进的阅读器）→ 只在新身份写进度，不建书架行。
  改写走 `BookshelfRepository` 的新方法 `migrateIdentity`，**不**删旧行再插新行（那会丢 `addedAt`、置顶与状态）。
- 进度按新身份写，章节名沿用对齐后的章节；旧身份的进度行保留（用户可以换回去）。
- **登记差异**：上游 `ChangeChapterSourceSheet` 会连“最新章节/字数”一起比较并显示；本仓只显示
  源名 + 章节数 + 对齐到的章节名——多出来的字段对“要不要换”没有帮助，且要多一次详情抓取。

### 决策 4 排版：四个新轴，字体族不打包字体（R4）

- 新增 `fontFamily`（跟随主题 / 衬线 / 无衬线 / 等宽）、`paragraphSpacing`（段距，0–1 倍字号）、
  `firstLineIndent`（首行缩进，0–2 个字符宽）、`pagePadding`（页边距：窄 16 / 中 24 / 宽 32）。
- **字体族用平台通用名**（`serif` / `sans-serif` / `monospace`），**不**打包字体资产：一套中文字体
  10+ MB，且要过 C-DEP-1/7 的许可核对；平台族名在三个目标上都有回退链，缺字体时落到系统默认，
  不会出现豆腐块。用户可见文案里写的就是“衬线/无衬线/等宽”，不承诺具体字面。
- 四个轴与既有四轴一起存在 `shared_preferences`，键仍是本 feature 私有（C-NET-9）；
  越界值在 `ReaderSettings` 工厂里钳制（与 ADR-0044 §决策 1 同一条理由：release 无 assert）。
- 段距与首行缩进**不改正文数据**：在段落拼接时插入换行 + 空格，渲染层保持一个 `Text`（可复制、可分页）。

## 影响

- `reader/domain/entities/reader_settings.dart` 与两个实现（store / notifier / sheet）扩到八个轴；
  `reader_style.dart` 生成带段距/缩进的正文。
- `reader_page.dart` 重排为「三区点击 + 可隐藏工具条 + 亮度遮罩 + 进度滑块」，AppBar 默认隐藏。
- 新增 `reader/presentation/widgets/reader_toc_sheet.dart`（R2）与 `reader_source_sheet.dart`（R3）。
- 新增 `book_source` 侧用例 `FindSourceCandidates`（跨源按书名搜）与 `bookshelf` 的
  `migrateIdentity`（R3 的身份迁移），两者都按 C-ARCH-2 经端口/装配根连接。

## 后果

- 好的方面：阅读器第一次有“读书软件”的骨架（沉浸式、进度、目录、换源、排版），且换源不再丢书架状态。
- 代价：`reader_page.dart` 变成阅读器里最大的文件；换源要跑一次聚合搜索，慢源会拖慢候选列表
  （复用 60 s 单源预算，见 ADR-0049）。
- 未闭环：系统亮度、逐页动画样式（拟真/覆盖）、书签与高亮标注、朗读——都登记在 `roadmap.md` §3.7。
