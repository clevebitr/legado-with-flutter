# ADR-0023 上游停运后的法律立场：方言兼容继续、真实语料最小化脱敏、免责与用途限制加强

- **状态：** Accepted（2026-10-11 由架构师裁决三件事）
- **日期：** 2026-10-11
- **关联：** ADR-0007、ADR-0014、C-UI-9、C-DEP-7、`NOTICE.md` §2/§3、
  `docs/dev/book-source.md`、`PLAN.md` §4（G2）、`test/fixtures/**/README.md`

## 背景

2026-10-11 核实：上游 `gedoor/legado` 仓库已**清空**——默认分支只剩一份停止侵权公告，
项目内容全部删除。这不是单纯的技术停运，而是一起刑事判决的结果：

| 事实 | 内容 |
|---|---|
| 罪名与刑罚 | 侵犯著作权罪；被告人葛某某、吴某某分别被判处**有期徒刑二年、一年九个月**，各并处罚金，追缴违法所得、没收作案工具（判决时间：2026 年 1 月） |
| 认定的侵权形态 | 用户导入「**书源**」文件后，经**深度链接**无需跳转即可在 App 内直接阅读；近 4000 部作品与报案方享有独家信息网络传播权的作品**相似度超 90%** |
| 获利方式 | 打赏、广告、引流带货，非法获利 **100 余万元** |
| 来源 | 上海市人民检察院网站转载《检察日报》报道；闵行区检察院通报（上游仓库公告所附的阅文知识产权保护公告）；上游仓库公告本身 |

本项目此前只在 `docs/dev/book-source.md` 顶部与 ADR-0014 记录了「上游已清空」这一**技术事实**
（并声明不改变任何决策）。架构师指出：该判决必须升级为**需要裁决的事项**，因为它直接决定三件事——
方言目标与命名、仓库内真实书源语料的分发、免责条款是否覆盖该形态。

> **范围声明：** 本 ADR 记录的是项目在**技术—许可—文档**层面的裁决，**不是法律意见**，
> 也不能替代法律意见。若将来需要正式法律意见，应作为独立事项提出。

## 决策

1. **继续以 Legado 方言为兼容目标，并沿用其字段命名**（`bookSourceName`、`ruleSearch`、…）。
   理由：字段名与语法是**互操作性契约**——用户导入的书源 JSON 必须能直接运行；
   判决认定的是「以营利为目的的深度链接经营」，与「实现一种公开规则方言的解析器」不是同一行为。
   ADR-0014 的范围与 `book-source.md` 的矩阵**不变**。
2. **仓库内保留脱敏后的最小真实语料**，并把它固化为长期规则：
   - 只保留**必要条目**，不整包收录书源合集；
   - **脱敏**：`bookSourceName` 改为中性名；`bookSourceUrl` / `bookUrlPattern` / `loginUrl` /
     `exploreUrl` 等一切 URL 的主机改为保留域（RFC 2606 的 `.test`）；
   - **规则串逐字保留**：它们是功能性选择器表达式，不含作品内容；
   - 每条语料必须在 `test/fixtures/**/README.md` 记录**来源、处理方式与用途**
     （现行做法见 `test/fixtures/book_sources/README.md`）。
3. **加强免责与用途限制**（`NOTICE.md` §2/§3）：
   - 新增明确条款：**禁止将本项目用于任何侵犯著作权的用途**，包括但不限于通过「书源」文件与
     深度链接抓取、聚合、缓存或传播未经授权的内容，以及以此获利；实施者自负全部责任；
   - 以**形态**（不写当事人身份细节）记录该判决作为风险提示；
   - 保留现有口径：不提供、不托管、不传播、不索引任何书源或阅读内容；用户自负合规责任；
   - 同一口径落到 C-UI-9 的「关于 → 法律声明」页：新增 ARB 键 `legalNoticesProhibitedUse`，
     `constraints.md` C-UI-9 的键列表同步。
4. **不改变许可策略**：项目仍为 GPL-3.0（ADR-0007），依赖许可要求不变（C-DEP-7）。
   本 ADR 不引入新的许可义务，也不改变与上游在许可层面的兼容关系。
5. **收紧容易、放宽困难：** 若将来要**移除**真实语料或去品牌化，属收紧，走普通 PR + 本 ADR 修订；
   若要在仓库内**扩大**真实语料范围（例如整包收录书源合集），必须先修订本 ADR。

## 后果

- `NOTICE.md` §2 增补上游现状（已清空 + 判决事实与来源）；§3 增加「禁止侵权用途」条款与风险提示。
- `constraints.md` C-UI-9 增加文案键 `legalNoticesProhibitedUse`；`lib/l10n/app_en.arb` 与
  `app_zh.arb` 同步（页面本身仍按 `PLAN.md` Phase 5 落地）。
- `book-source.md` 顶部与 ADR-0014 的「上游已清空」事实附注保留——本 ADR 是其**法律层面**的对应裁决。
- B4 的语料形态按决策 2 执行：真实书源（仅默认规则）+ 真实 HTML，二者都按脱敏规则处理并记录来源。
- 该判决**不改变**任何 `C-*` 约束的判定方式，也不改变 M0/M1/M2 分期与 `book-source.md` §3 矩阵。

## 备选方案

| 方案 | 否决原因 |
|---|---|
| 转向自有方言（放弃导入兼容） | 丢掉核心兼容卖点，ADR-0014 与已完成的模型 / 引擎需重做；且判决针对的是经营行为，不是方言解析本身 |
| 文档全面去品牌化 | 字段名仍必须是 Legado 的（否则无法导入），半去品牌化只会让兼容目标变得含糊 |
| 删除全部真实语料，改用合成语料 | `PLAN.md` 2.1 与 G2 的「真实书源」验收将失效，且合成语料无法暴露真实导出里的字段构成（该做法在 F2 已被否决一次） |
| 真实语料移出仓库，仅本地 / CI 注入 | CI 无网络，测试不可复现，本地与 CI 结果不一致 |
| 只靠现有 `NOTICE.md` §3 免责 | 判决认定的形态正是「书源 + 深度链接」，而现有条款只有「不鼓励」而无明确禁止与责任划分 |
| 先取得法律意见再定 | 可作为**后续**动作，但不作为当前阻塞项：本 ADR 的三条裁决都取保守方向（保留最小脱敏语料 + 加强限制），不增加暴露面 |
