# ADR-0095 目录按卷折叠：卷标题是一行可折叠的组头，搜索时忽略折叠

- **状态：** Accepted（2026-10-30，M36 规格前置；补上游目录面板的「按卷」能力）
- **日期：** 2026-10-30
- **关联：** ADR-0051 §决策 2（目录：当前章居中 / 正倒序 / 搜索）、`book-source.md` §3 矩阵（`isVolume` 已建模）、
  ADR-0069（卷标题无 URL 时的占位）；上游 `ui/book/read/ReadBookTocSheet`（`isVolume` 渲染为标题行）

## 背景

`Chapter.isVolume` 从 M25 起就能解析（`book-source.md` §3），`FetchToc` 也给没有地址的卷标题保留了占位地址，
正文流程把它当「章首章头」画。但**目录面板仍然是平铺列表**：一部三千章、分二十卷的书，卷名与章节混在一起，
用户滚动时没有任何层级感；上游把卷标题画成一条不可跳转的组头，其下是章节。

## 决策

### 决策 1 卷标题是一行**组头**，点击折叠/展开，不是跳转

- 渲染：`ListTile` + `leading` 展开箭头（`expand_more` / `chevron_right`）+ 加粗标题，`onTap` 只切换折叠。
- 折叠状态按**卷标题的原索引**记在一个 `Set<int>` 里；默认全部展开（新开的 sheet 状态是空的，所以总是展开）。
- 折叠只隐藏它**之后、下一个卷标题之前**的章节；卷标题本身永远可见（否则就没法展开回来）。

### 决策 2 搜索与倒序都仍然成立

- **搜索时忽略折叠**：有查询时所有命中行都显示（包括被折叠卷里的），否则「搜到了却看不见」是比层级感更糟的体验。
- **倒序仍是整表的反转**：卷标题一起反转，卷内章节的相对顺序跟着反转后的表走——与 ADR-0051 §决策 2「倒序是视图」一致。
- **当前章居中**的估算继续用「它前面有几项 × 行高」；组头与行同高（`ListTile` 默认 56），估算不受影响。

### 决策 3 卷标题不进入阅读流程

点组头**不**跳转、不触发正文请求：卷标题不是可读章节（正文流程给它的占位页已经由 ADR-0069 G8 兜底）。
用户从目录跳到卷内某一章，路径没有变化。

## 影响

- `reader_toc_sheet.dart`：显示项从「章节行」变成「组头 / 章节行」两种，多一个折叠集合与开关方法。
- 测试：目录 sheet 三条（卷标题可折叠且不回调 `onSelected`、搜索忽略折叠、倒序把卷标题一起反转）。

## 后果

- 好处：长书目录第一次有层级；折叠让「我在第几卷」一眼可见。
- 代价：目录 sheet 的显示模型多一层；行数变化让居中估算在「折叠状态下」略偏，用户一滑就修正（与原来同一条近似）。
- 不做：按卷跳转的二级目录、卷内页码统计、记住折叠状态跨会话（都是「目录增强」的下一步，暂无需求证据）。
