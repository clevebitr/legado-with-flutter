# ADR-0007 许可证选择

- **状态：** **Proposed（待裁决）**
- **日期：** 2026-10-10
- **关联：** `CONTRIBUTING.md`、`README.md`、`docs/dev/book-source.md`

## 背景

旧文档互相矛盾：

- `AGENTS.md` §1 写「开源协议与免责声明：遵循 Legado 社区规范」。
- `CONTRIBUTING.md` §8 写「本项目采用 MIT License」，并链接了并不存在的 `./LICENSE`。

上游 **Legado 项目采用 GPL-3.0**。许可证选择取决于本项目的实现来源：

| 情形 | 结论 |
|---|---|
| 仅**复现规则方言**（自行实现解析），未复制上游代码 | MIT 可用，且必须写明与 Legado 无隶属关系 |
| **移植或改写了上游实现代码** | 必须 GPL-3.0，MIT 不可用 |
| 仅使用用户提供的书源 JSON 数据 | 数据不构成代码衍生，不影响本项目许可证 |

## 建议方案（待裁决）

1. 若本项目确认为**独立实现**（无上游代码移植）：采用 **MIT**，
   并新增 `NOTICE.md` 声明「本项目是独立实现，与 Legado 项目及其作者无隶属关系，
   书源规则方言的兼容性不构成对上游代码的复制」。
2. 若曾参考或移植上游实现：改用 **GPL-3.0**，并保留上游版权声明。
3. 无论采用哪种，都必须新增免责声明文档，说明本项目不提供、不托管任何书源内容，
   用户自行承担导入第三方书源的责任。

## 后果

- 在裁决完成前**不创建 `LICENSE` 文件**；`README.md` 与 `CONTRIBUTING.md`
  只标记「待裁决（ADR-0007）」，不写具体许可证名称。
- 裁决后必须同时更新：`LICENSE`、`README.md`、`CONTRIBUTING.md`、`NOTICE.md`，
  并把本 ADR 状态改为 Accepted。
- 若选择 GPL-3.0，需重新评估 `pubspec.yaml` 中依赖的许可证兼容性。

## 待裁决问题

1. 本项目是否包含任何来自 Legado 的代码移植？（影响 MIT 是否可用）
2. 是否需要保留上游版权声明文件？
3. 免责声明放在 `NOTICE.md` 还是 `docs/legal/`？
